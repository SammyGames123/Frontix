# Frontix

Frontix is a real-time strategy (RTS) game focused on territory control, tactical expansion, and fast-paced decision making.

## Features

- Zone-based control system
- Real-time troop movement
- Competitive solo gameplay
- Lightweight browser-based client

## Tech Stack

- React + Canvas
- Node.js + Socket.IO
- TypeScript

## Status

Early MVP build. Actively in development.

## Roadmap

- Custom game mechanics
- Visual polish
- Multiplayer improvements
- Unique Frontix features
